How Fineatch AI Works
1
Generate / Import Dataset
Click ▶ Run Reconciliation to generate 65+ synthetic economic events via a seeded PRNG (Mulberry32, seed #84231), producing Bank, GL & AP records. Or import your own CSV files via ⊕ Import Data — schema is auto-detected from column headers.
2
3-Pass Reconciliation Engine
Pass 1 Exact (100%): payment reference + amount. Pass 2 Fuzzy (70–99%): amount ±0.5%, date proximity ≤3 days, narration similarity. Pass 3 Heuristic (40–69%): vendor/counterparty name matching. Unmatched items become open exceptions.
3
Batch Resolution Agent (FinAgentV1)
The agent processes every open exception and attempts resolution: rounding (AMT_MISMATCH), NEFT timing (DATE_GAP), split invoices (SPLIT_PAYMENT), FX gain/loss (FX_VARIANCE). Unresolvable items (e.g. DUPE_CANDIDATE) are surfaced for human review — never hidden.
4
Scoring, Forecasting & Tax Classification
Each dataset receives a composite score (0–100) based on match rate (40%), AP settlement (25%), agent coverage (20%), and exception penalty (15%). A 30-day cash position forecast with p10–p90 bands is computed. GL entries are classified for GST-ITC, TDS-192, and GST-OUT exposure.
